# Intersection Rush
 
Intersection Rush is a traffic management simulation built with SplashKit. Players control traffic lights to prevent congestion, maximise traffic flow, and avoid gridlock while competing against fixed-time and adaptive AI traffic controllers.
 
## Requirements
 
Before running the game, ensure the following are installed:
 
- SplashKit SDK
- .NET SDK
 
## Setup
 
1. Create a new SplashKit console project:
 
```bash
skm new console
skm dotnet restore
skm run
